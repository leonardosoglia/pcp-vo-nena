## Princípio metodológico

Pra cada capítulo do TCC e do relatório de estágio:

1. **Pesquisa web ampla** — buscar trabalhos similares (TCCs, dissertações, artigos)
2. **Identificar autores recorrentes** — quem é citado em vários trabalhos é referência canônica
3. **Triangular fontes** — não basear em um único trabalho
4. **Citar com rigor ABNT** — autor, ano, editora, página quando houver
